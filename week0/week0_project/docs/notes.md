# Week 0 Notes

## 1. Paths

- `/` is the root directory.
- `~` is the current user's home directory.
- `.` means the current directory.
- `..` means the parent directory.

## 3. Permission


## 4. Redirection

```bash
command > file.log
command >> file.log
command 2> error.log
command > all.log 2>&1
```
